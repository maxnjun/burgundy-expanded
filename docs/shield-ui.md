# 공용 보드 방패 배치 UI

2026-10-18. 실제 규칙은 **방패 확장 ·18종 능력·유지비·종료 점수 (로컬)**로 시작한다. 과거 UI 검증 모드/저장은 능력이 꺼진 상태로 유지한다. 게임 공급은 여전히 프로젝트 연습 공급이며, 방패의 AI·온라인·팀/솔로 조합 및 전체 프로젝트 완성은 아니다.

활성 형식은 shield-rules-v1, effectsActive:true, options:{rules:true}. rules에 수도원 공유 대상,16번 사용 차례 키, 단계 말 freeDone/paid 이력을 저장한다. 기존 preview-v1은 그대로 파싱하며 자동으로 능력을 켜지 않는다.

**U15 해결 — 사용자 확정 프로젝트 규칙:** 방패9로 판매 타일당 은화1을 계산한 뒤 수도원3의 은화1을 한 번 추가한다. 동시 보유 판매를 허용하며 출판사 공식 판정이라고 주장하지 않는다.

단계 말에는14/15 직접 배치와 그에 따른 성/선박/건물 선택을 마친 뒤, 각 소유 방패의 은화1/일꾼1(3보유 시)/제거를 고른다. 모두 처리하면 자동으로 광산 수입과 보충 또는 E 종료 정산을 실행한다. 제거된 방패는 능력·종료 점수에 포함하지 않고 공급 슬롯은 다시 채우지 않는다.

아래의 기존 검증 모드 설명은 레거시 저장/조작을 위한 기록이다. 활성 모드는 게임 준비의 별도 ‘방패 확장’ 체크박스를 사용한다.

## 사용

게임 준비 → ‘방패 UI 검증 모드 (능력·유지비 미구현, 로컬 전용)’ 선택 → 새 연습 시작. 기존 진행을 보관하려면 먼저 저장 파일을 내보낸다. 기존 저장을 자동으로 다른 규칙 모드로 바꾸지 않는다. 이 모드에서는 AI와 다른 디자인 보기를 비활성화한다.

주사위 선택 → 공용 보드 방패 선택 → 번호/능력 설명과 두 주사위의 보정 일꾼 비용 확인 → 강조된 자기 영지의 성 터치로 획득. 별도 획득 버튼은 사용하지 않으며 주사위 미선택 시 비용 배지를 숨긴다. 이미 장착한 성을 선택하면 제거할 기존 방패를 확인해야 한다. 한 주사위라도 사용했다면 획득할 수 없다. 일꾼 보정은 두 주사위 각각에 적용한다. 새로고침·저장 내보내기/가져오기에서 장착 및 빈 슬롯이 보존된다.

## 상태와 레이아웃

- GameState.extensionStates.shields: shield-layout-preview-v1, effectsActive:false. 설정도 shields/options/uiPreview:true를 요구한다. 완성 엔진을 연결할 때 이 검증 상태를 정식 활성 상태로 조용히 재해석하지 않는다.
- 여섯 공급처 그룹, 슬롯 ID는 shield:depot:{1..6}:{index}. 공급처 번호는 배열 순서 대신 슬롯의 depot 필드를 사용한다. 같은 SVG 안에서 그룹·타일·상품을 함께 확대한다.
- 공식 PDF p.17에 따라2인6개,3인9개,4인12개를18종에서 중복 없이 추첨한다. 중앙 상단/좌우 상·하단/중앙 하단의 여섯 고정 위치 안에1~2개를 표시한다. 자체 SVG 방패와 번호/능력 도움말, 터치·키보드 강조를 사용한다.
- 획득 시 shieldNumber:null. 동일 ID·크기·좌표의 회색 실루엣을 남긴다. 빈 슬롯은 버튼/탭 정지점/획득 대상으로 사용하지 않는다. 다른 타일 좌표를 바꾸지 않는다.
- 공식 규칙은 **방패 보충 없음**이다. 단계 말 육각 타일 보충과 상품 보존 과정에서도 기존 슬롯의 점유/빈 상태를 그대로 유지한다.
- mounted/removed/boxed와 공급처 슬롯의18개 물리 방패 ID를 함께 검증한다. 중복·잘못된 슬롯/공급처·다른 소유자·없는 성·위조 효과 활성화를 거절한다. 기존 기본판 v1 저장은 계속 허용한다. 저장은 구조 검증이며 인증된 행동 이력의 증명은 아니다.
- 모바일은 SVG 최소660px의 가로 스크롤로 방패 터치 크기를 보존한다. 화면 폭을 넘어 페이지 전체가 늘어나지 않으며 공급처 대응은 고정이다. 일반 스크롤/기존 확대 기능을 유지한다.
