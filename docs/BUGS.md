## 2026-10-25 Ver.2 14항목 — 검증 완료 (운영 미배포)

- 일반 시장 보상은 이미 번호 공급처로 제한되어 있었다. 무료 검은 획득과 별도 유료 구매를 구분하는 UI·서버 위조 요청 회귀 검사를 추가했다.
- 무역로 진행이 use-die 판매에만 연결되어 보너스 판매를 빠뜨렸다. 상품을 제거하는 공통 판매 처리에서 1회 진행하도록 이동했다.
- 시청 무료 배치 선택지에 포도가 없었다. 시청·포도 무료 배치·기중기/무역로의 시청 효과에서 같은 생성기를 재사용하고, 정확한 구형 선택지만 안전하게 확장한다.
- 포도 즉시 배치를 임시 방향 선택과 혼용했다. 칸 선택·180도 전환·확정 전 미리보기만 UI 상태에 저장하며 실제 보상은 엔진 확정 후 처리한다. 온라인에서는 실제 주사위 선택 시 성 추가 행동 선택지가 먼저 실행되지 않게 분리한다.
- 방패 PNG 위 투명 강조 rect에 legacy hover 흰 fill이 적용됐다. path 전용 fill로 제한하고 PNG는 투명 외곽선만 사용한다. 상위 영지 brightness와 강조 그림자도 PNG에 적용하지 않는다. 툴팁의 크기·위치는 유지한다.
- 기록의 +0/좌표와 그림 없는 주사위, 숫자로 된 일꾼 비용, 텍스트 토큰 선택, 획득 보너스 누락을 공통 표시로 정리한다. 기존 문자열 로그·저장 형식은 유지한다.
- 개인 드래그 모드 버튼을 제거하고 공용 보드 모드는 보존한다. 상단 고정은 기본 ON이며 로컬/온라인 설정에서 브라우저에 저장한다.
- 전체 core 494/494, boards 33/33, 배포 PNG 80개 및 기존 타일/아이콘 규격 검사를 통과했다. 전체 PC179·Chrome터치46·WebKit41·DPR2 반복 색상6 및 최종 빌드 UI2개 통과. 상세 결과는 `docs/qa/ver2-14.md`. Redis·운영 방 변경 없음.
