# 온라인 2인 테스트 버그 기록

이 문서는 친구와 테스트 사이트에서 재현한 문제를 기록한다. 화면/코드의 실제 확인 없이 증상이나 해결 상태를 추정하지 않는다.

## 현재 항목

| ID | 상태 | 증상과 근거 | 다음 조치 |
|---|---|---|---|
| ONLINE-001 | 제보·재현 대기 | 사용자 로컬 온라인 2인 플레이에서 게임은 진행되지만 여러 버그가 남아 있다고 보고함. 개별 재현 절차는 아직 없음. | 테스트 사이트에서 아래 양식으로 증상을 각각 기록하고 원인을 재현한다. |
| CI-001 | 로컬 통과·원격 CI 대기 | GitHub main `b99737c`의 [Game CI](https://github.com/maxnjun/burgundy-expanded/actions/runs/39659228289)에서 PC 143통과·3제외·1실패. 드래그 모드를 끈 뒤 CSS의 `touch-action`은 양방향 기본 스크롤에 해당하는 `manipulation`인데 기존 검사는 과거의 `pan-y pinch-zoom`을 기대했다. | 드래그 모드 안팎을 확인하는 관련 PC·390터치 2/2 통과. 새 main CI를 확인한다. CI 실패 동안 자동 테스트 배포는 차단한다. |
| CI-002 | 로컬 통과·원격 CI 대기 | 전체 PC 회귀에서 온라인 시작 성 테스트 143통과·3제외·1실패. 게스트의 시작 성 배치는 서버에서 성공했지만, 호스트 화면이 새 revision을 받기 전에 바로 클릭하여 서버가 오래된 행동을 409로 거절했다. 실제 서버의 동시 입력 보호는 정상. | 기존 `waitOnlineFresh`로 호스트의 최신 상태 동기화를 확인한 뒤 시작 성을 누르는 단독 재검사 1/1 통과. 새 main CI를 확인한다. |

## 새 버그 양식

```text
ID / 상태: OPEN / REPRODUCED / FIXED / RETEST
게임 버전(화면 하단의 커밋 SHA):
모드 / 방 단계 / 현재 차례:
기기·OS·브라우저 버전 / 네트워크:
재현 순서(1, 2, 3):
예상 결과 / 실제 결과:
재현 빈도 / 다른 플레이어 화면 결과:
오류 문구·캡처 위치(있을 때):
관련 테스트 / 수정 커밋 / 재검증 결과:
```

우선순위는 게임방·저장 손실이나 권한 문제 P0, 진행 차단 P1, 화면/조작 문제 P2로 적는다. 공개 GitHub 문서에는 **재접속 토큰, 전체 localStorage, 방 JSON, 비밀키, 비공개 게임 데이터나 개인정보**를 넣지 않는다. 방 코드는 필요하면 익명화하고, 원본 로그·캡처는 비공개 로컬 경로에만 보관한다.
