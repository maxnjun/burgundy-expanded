# 차례 제어와 화면 정리 (2026-10-20)

## 버튼과 엔진

상단 행동 표시줄 오른쪽에 `되돌리기`, `이전 행동으로`, `턴 종료` 순서로 공통 TurnControls를 배치한다. 활성 배경 #A83232 / 테두리 #752020 / 크림색 글자, hover #BF4343. 비활성 상태도 적색 계열이며 pointer 실행을 차단한다. PC 한 줄, 좁은 화면에서는 별도 줄로 감싼다. 모든 확정 행동은 기존 applyCoreAction 경로를 유지한다.

`턴 종료`는 엔진의 validateCoreAction(end-turn)을 사용하며 양 주사위·필수 선택을 건너뛰지 않는다. 로컬의 미확정 선택/교체 확인 중에도 버튼을 비활성화한다. 기존 자동 턴/라운드/단계 진행은 유지한다. 따라서 자동 종료된 차례는 되돌릴 수 없으며, 선택 가능한 추가 구매 등이 남은 경우 버튼으로 정상 종료할 수 있다.

## 스냅샷

src/game/turn-history.ts는 GameState 전체와 행동 로그를 structuredClone으로 저장한다. 주사위, 자원, 공급, 점수 원장, 모든 확장 상태, 추가/필수 효과 및 random.seed/cursor와 revision이 포함된다. 자원이나 점수를 역산하지 않는다. React의 임시 선택·확인·특수 모드는 복원 시 해제하며 보기 배율은 유지한다.

턴 키는 시드·단계·라운드·현재 플레이어·행동 완료 플레이어 목록으로 구분한다. 차례 진입 시 시작 스냅샷을 만들고, 확정 행동 직전 스냅샷을 누적한다. 필수 선택이 진행 중이면 새로운 Undo 단위를 만들지 않고 원래 행동에 포함한다. 필수 선택·미확정 대상·교체 확인 중에는 취소 기능 또는 필수 선택 해결이 우선이다. 같은 차례의 마지막 완료 행동을 역순으로 취소하며 redo 기록은 만들지 않는다. 새 행동은 현재 상태에서 새 스냅샷을 기록한다.

`되돌리기`는 확인창 ‘이번 차례의 모든 행동을 취소할까요?’에 동의해야 시작 상태로 복원한다. 마지막 행동 Undo는 즉시 실행한다. 차례/라운드/단계 경계가 바뀌거나 종료되면 이전 기록을 폐기한다. 다른 플레이어 소유의 별도 행동이 적용되면 그 이전 기록도 무효화한다. AI 좌석에서는 일시정지 여부와 관계없이 Undo 버튼을 비활성화한다. AI 전략은 변경하지 않는다.

## 저장·불러오기 제한

기존 burgundy-local-v1 파일 형식과 자동 저장 경로는 그대로다. Undo 메타데이터는 파일에 포함하지 않는다. 파일 불러오기 및 새로고침에서는 이전 Undo 기록을 초기화한다. 불러온 진행의 실제 턴 시작 상태를 알 수 없으므로 **그 차례의 ‘되돌리기’는 다음 차례까지 비활성화**하며 이유를 표시한다. 불러온 뒤 새로 확정한 행동은 ‘이전 행동으로’ 취소할 수 있다. 다음 차례에 들어가면 두 Undo 모두 정상적으로 시작된다. 가져오기 실패 시 진행과 기록을 유지한다.

저장 파일 내보내기/불러오기는 기존 ‘⚙ 게임 준비’ 설정 안으로 옮겼다. 상시 저장 패널은 없으며 자동 저장 오류는 기존 alert로 유지한다.

## 온라인 지원 범위

온라인 Undo는 **지원하지 않는다**. 서버가 숨긴 공급·난수와 이미 공개된 결과를 안전하게 철회하는 합의 프로토콜이 없기 때문이다. 두 버튼은 비활성화하고 화면·title에 이유를 표시한다. 서버도 undo/undo-action/undo-turn/restore-state 명령을 거절한다. 좌석 인증·revision 검사·다른 좌석 행동 금지는 기존 순서대로 유지하며, 거절 후 상태가 변하지 않는지 검사한다.

온라인 턴 종료는 서버가 제공하는 합법 end-turn만 실행하고, 기존 동기화·재접속 경로를 사용한다. 서버 게임 상태를 클라이언트 스냅샷으로 대체하는 기능은 추가하지 않았다.

## 방패 UI와 보존 범위

‘방패 확장 · 능력 적용 중’, 긴 상시 설명, ‘장착한 방패 없음’/장착 목록은 제거했다. 실제 방패 슬롯·성 위 방패·상세 대화상자는 유지한다. 방패6 공유 대상/방패16 눈 변경, 현재 장착 대상·불가능 사유와 필수 능력/유지비 선택은 유지한다. 방패9+수도원3 프로젝트 규칙 설명은 접이식 기존 규칙 도움말로 이동했다.

공용 보드 좌표/크기/이미지, 포도밭4층과 시작1+층4 토큰, 여관·무역로·일반 규칙 및 AI 전략은 변경하지 않았다. 기존 사용자 PNG2개 및 문서 여관 구간은 별도 미커밋 상태로 보존한다.
