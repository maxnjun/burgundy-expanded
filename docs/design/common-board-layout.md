# 공용 보드 UI 좌표 설계 (2026-10-20)

규칙/공급/저장과 분리된 표시 좌표. 사용자 최신 텍스트 지시 기준. 마지막 빨간 선 이미지는 메시지에 첨부되지 않아 픽셀 일치라고 주장하지 않는다. 앞선 참고 사진은 배치 관계만 참조.

## 설계 확정 후 적용할 구조
- 중간 확대안 1200×1330 → 최종 950×1030. 면적 약 38.7% 감소, 가로/세로 비율 0.902→0.922. 최초 기준은 방패 780×740/일반 640×740.
- 왼쪽 패널 x18 y18 w390 h205: A~E 점수 위, 실제 남은 라운드 상품 아래. 공급 완료/대기/현재 구분.
- 오른쪽 패널 x542 y18 w390 h205: 순서 트랙, 눈금/위치, 플레이어 색상. 중앙 상단 바 없음.
- 타일 폭60(다인 기존50보다 커짐), 방패 원본 SVG 크기 유지. 확대는 native SVG 크기×배율이며 작은 화면은 스크롤.
