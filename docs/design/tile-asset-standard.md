## 수학적 규격

정의: `src/app/tile-standard.json`, `estate-geometry.ts`, `tile-frame.tsx`.

- 영지 R=48, halfWidth=24√3=41.569219381653056. 중심 `(310+48√3(q+r/2),282+72r)` 그대로.
- 공통 아트 viewBox: `0 0 100 115.47005383792515`, 중심 `(50,57.735026918962575)`.
- 꼭짓점: `(100,28.867513459481287)`, `(100,86.60254037844386)`, `(50,115.47005383792515)`, `(0,86.60254037844386)`, `(0,28.867513459481287)`, `(50,0)`.
- 공유 변은 동일 좌표다. 전체 타일 영역과 빈 칸의 외곽 크기가 같다.
- 안쪽 테두리는 inset 0→0.5(어두운 선), 0.5→1.85(하이라이트/기본색/음영 gradient), 1.85→2.2(안쪽 선)인 evenodd 채움이다. 중앙 정렬 stroke를 사용하지 않는다. 색상만 종류별 팔레트에서 가져온다.
- 아트 clip은 같은 꼭짓점 공식의 inset 2.2. 정사각 PNG는 H×H로 중앙 정렬하며 균일한 스케일만 쓴다. 벡터 그림은 기존 110높이 일러스트 좌표를 공통 중심으로 한 번만 이동한다. 타입별 위치/배율 예외는 금지한다.
- CSS 보관함 표시도 높이=폭×2/√3. 부모 버튼에서 별도로 육각형을 자르지 않는다.

## 파생 에셋과 재생성

원본 `public/tiles/*.png`를 덮어쓰지 않는다. `public/tiles/estate/` 및 `normalize-estate-tiles.py`는 과거 자료이며 현재 렌더러에서 읽지 않는다. 새로운 타일에 과거 삼각 분할 워핑을 사용하지 않는다.

1. 성/광산/선박/수도원27·28: `scripts/extract-tile-illustrations.py`. 검수된 원본 해시·안쪽 테두리 contour와 보존 마스크를 적용한다. 기존 파생 5개는 이번에 재작성하지 않았다. 같은 알고리즘으로 알파 지지함수를 측정하여 1024 정사각 캔버스 안쪽 육각형에 등방성으로 맞춘다. 배율·중심은 빌드 시 측정 결과이며 렌더링 보정값이 아니다.
2. 여관: `scripts/extract-inn-illustration.py`. 검수한 금색 외곽 테두리 안쪽 contour를 분리하고 같은 등방성 fitting/안쪽 테두리를 사용한다. 여러 색의 내부 패널 구분선은 일러스트의 일부로 보존한다. 팔레트는 실제 원본 금색 테두리의 밝기 분위 RGB다. 원본 변경 시 재검수한다.
3. 기중기/거위: `scripts/normalize-center-illustrations.py`. 알파 bbox를 trim하고 동일 32px 여백/최대 변 960px로 1024 캔버스 중앙에 비율을 보존하여 넣는다. 렌더링은 모든 중앙 일러스트에 공통 66단위 사각형을 쓴다.
4. `manifest.json`/`center-manifest.json`에 원본·출력 SHA256, 알파 경계 및 팔레트를 기록한다. URL의 출력 해시가 캐시를 구분한다. 새 원본의 그림을 손상시키는 무검수 crop/AI 보완은 금지한다.

기존 작업에서 미커밋 상태였던 수도원27·28 원본은 현재 검수된 파생 PNG/manifest의 입력과 일치하지만, Git HEAD의 원본과는 다르다. 이번 커밋에는 이 기존 원본 변경을 임의로 포함하지 않는다. 따라서 현재 작업 트리의 검사와 렌더링은 통과하지만, 깨끗한 clone에서 엄격한 원본 해시 검사/재추출을 하려면 해당 원본2개를 별도 승인·백업해야 한다. 검사 실패를 숨기거나 원본/마스크를 임의 교체하지 않는다. 현재 게임이 사용하는 파생 PNG는 이미 백업된 기존 파일 그대로다.

## 승인 자원 아이콘

`scripts/normalize-resource-icons.py`는 승인 첨부 원본에서 검은 외곽선으로 닫힌 영역만 보존한다. 체크무늬는 실제 RGB 배경이므로 바깥쪽 flood fill을 알파0으로 바꾸며 투명 픽셀 RGB도0으로 만든다. 원본 RGB는 재표본화하지 않는다. 알파 bbox를 trim하고 긴 변+32px 정사각형에 중앙 정렬한다.

- 은화:774×774, 알파 bbox `(16,26,758,747)`.
- 일꾼:750×750, 알파 bbox `(71,16,679,734)`.
- 둘 다 같은 정사각 표시 크기와 `contain/meet`. 실제 원본 비율 보존. 출력 해시로 캐시 구분.
- `ResourceIcon`: HTML img, 기본24px. `ResourceGlyph`: SVG image, 기본20단위. 작은 실제 표시16/20/24/32px를 검사한다.
- 개인 자원/행동 표시줄/기존 데모의 이모지, 은행 SVG의 동전, 여관 구매 비용, 검은 공급처 구매 비용에 적용. 방패2·3의 일꾼,8·9의 은화는 번호 위의 공통 아이콘 레이어다. 숫자 아래 기존 ◆/✦/✧는 종료점수 구분이므로 자원 아이콘으로 바꾸지 않는다.
- 수도원14는 공통 `TileResourceEffect`로 일꾼2→4 효과를 표시한다. 번호/아이콘/화살표 위치와 크기는 JSON의 effect 설정을 재사용한다. 규칙이나 자원 수량은 바뀌지 않는다.
- 자원이 있는 방패는 아이콘 y=-32/크기12, 번호 y=0/최대18, 종료점수 y=15인 세 줄로 표시한다. 17·23 요청 크기의 실제 SVG bbox 비겹침을 검사하며 큰 요청도 예약된 번호 영역에 맞춘다. 글꼴은 Arial/sans-serif로 통일한다. 방패 외곽과 클릭 영역은 바꾸지 않는다.

### 원본 합성 그림의 제한

수도원28 등 기존 합성 PNG 안에 이미 그려진 자원 그림은 원본 장면과 합쳐져 있다. 이를 지우면 뒤의 건물 그림을 복원해야 하므로 임의 인페인팅·덮어쓰기는 하지 않았다. 해당 기존 PNG 내부 자원 그림은 아직 공통 PNG 레이어로 분리되지 않았다. 새/재제작 효과 그림에는 승인 자원 파일을 별도 합성해야 하며, 이 제한을 전체 자원 교체 완료로 보고하지 않는다. 이미 인쇄된27·28 번호도 중복 SVG 번호를 추가하지 않는다.
