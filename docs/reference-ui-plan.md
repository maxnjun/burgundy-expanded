# 첨부 화면을 기준으로 한 개발 계획

2026-10-17. 목표는 첨부한 웹 버건디 화면의 정보 배치와 실제 보드게임 조작 흐름을 재현하는 것이다. 기존 아이보리·골드 화면은 보기 전환으로 유지한다. 원본 서비스의 이미지·소스는 사용하지 않는다.

## 첨부 화면에서 확인한 구성

공용 보드가 상단에 있고 플레이어별 판이 아래에 나란히 놓인다. 개인 판의 위에는 상품, 점수, 색 주사위가 있고, 일꾼/은화와 37칸 영지, 하단의 세 보관 칸이 있다. 나무 테이블과 양피지 계열 배경, 색상별 지형, 주사위 점 표시, 현재 차례 안내를 사용한다. 첨부에는 공용 보드 전체가 없고 실제 조작 화면/규칙/숨은 상태도 없으므로 스크린샷 한 장으로 완전한 기능 동일성을 증명할 수 없다. 화면의 1번 영지는 기존 판본일 가능성을 단정하지 않고 **Special Edition 1번으로 등록하지 않는다**.

## 구현한 첫 단계

- 기본 화면을 테이블 보기로 구성. 자체 CSS 나무/종이 배경, 상단 공용 공급처, 아래 플레이어 영지, 공간에 따른 줄바꿈.
- 개인 판에 상품 종류/개수, 개인 주사위 선택, 점수, 자원, 보관함을 모았다. 칸의 눈을 자체 SVG 점으로 표현한다. 기존 공식 SE2 데이터와 게임 상태를 그대로 렌더링한다.
- 현재 차례 안내를 상단에 고정하고 기존 디자인으로 돌아가는 버튼을 제공한다. 전체/개별 배율, 현재 차례 중심 보기 유지.
- A~E 25라운드, 광산/수도원2 수입, 주입 공급 보충, 최종 자원/검증된 수도원 점수, 승자와 동점 판정.
- 선박 배치의 상품 종류 선택/보관 한도, 순서 트랙 전진과 동률 스택 처리. 대기 선택도 저장 가능.
- 자동 저장/새로고침 복구, JSON 내보내기·불러오기, 손상·미지원 저장 거절. 자동 저장 손상 시 원본을 자동 덮어쓰지 않는다.

## 다음 구현 순서와 완료 기준

1. **공식 공급 검증**: 인원별 공용 보드 슬롯 및 164개 타일의 종별/뒷면 전수 구성. 3인 6번 예외 슬롯을 특정해야 한다. 현재 연습 공급은 이를 대체하는 공식 자료가 아니다.
2. **전체 타일 효과 큐**: 성의 자유 추가 행동, 시청의 추가 배치와 연쇄, 시장/목공소/교회 획득, 창고 판매. 선택 전후 구매 타이밍과 보관 폐기를 회귀 테스트한다.
3. **수도원 전체 효과**: 5의 인접 공급처, 6의 차례당 획득, 8~12 보정, 16~23의 미확정 건물 도상 매핑. 각각 공식 본문/도상을 대조하고 테스트한다.
4. **정식 준비**: 공식 공급 카탈로그를 기반으로 2~4인 준비, 색 선택, 시작 플레이어와 시작 성 선택을 연결한다. 초기 성 배치 무득점 확인.
5. **동일성 검증**: 정식 준비부터 25라운드 종료까지 획득·배치·판매·연쇄 효과가 섞인 시나리오를 통과시킨다. 지금의 일꾼 위주 25라운드 테스트만으로 이 조건을 통과했다고 주장하지 않는다.
6. **표현 정밀화**: 자체 SVG 건물/가축/선박 아이콘과 공용 보드 점수/순서/보너스 표시를 다듬는다. 별도 확장/네트워크 대전은 기본판 완료 후 작업한다.

검증된 공식 영지는 현재 SE2 1개다. 나머지 보드는 공개 자료를 계속 조사하되 확인되지 않은 칸을 만들지 않는다. 완전한 기본판이나 첨부 서비스와 완벽히 동일한 상태는 아직 아니다.
