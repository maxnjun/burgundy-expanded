2026-10-18. 사용자 첨부 `reference/two-player-supply-user.png`를 기준으로 구현했다. 사진의 첫 페이즈에 나온 타일 종류/마릿수를 고정하지 않고, 공급 칸의 지형만 고정한다.

중앙은 검은 뒷면 타일4개를 마름모로 배치한다. 특정 앞면 종류를 고정하지 않는다.

## 실제 동작

- 새2인 게임은 `se:main:2` 레시피와 `project:base-160-v1` 공급을 사용한다.
- 타일 카탈로그는 가축24개를 사용하는 사용자 확정 구성이다. 다른136개와 합쳐160개이며 시작 성2개도 이 카탈로그에서 꺼낸다. 거위 확장은 기본 공급에 넣지 않는다.
- A단계부터 종류·뒷면에 맞는 남은 공급에서 seed 난수로 비복원 추첨한다.
- B~E로 넘어갈 때 공급처와 검은 공급처에 남아 있는 육각 타일을 버린 구역으로 이동하고, 같은 지형/뒷면의 새 타일을 보충한다. 이미 획득한 타일이나 배치한 타일은 버리지 않는다.
- 공급처의 상품은 남긴다. 단계 상품5개를 다음 라운드 상품으로 이동한다.
- 버린 타일을 공급에 다시 섞지 않는다. 같은 seed/진행은 동일 결과이며 다른 seed는 다른 추첨 결과를 만든다.
- 이전 저장 게임은 자동으로 초기화하지 않는다. 기존 진행에서 새 배치를 쓰려면 준비 화면에서2인을 선택하고 새 연습을 시작한다.
- 3·4인 레시피와 기존 연습 공급은 유지된다. 사용자 지정 가축 수로3·4인 전체 공급이 충분한지는 별도 문제이며 이번2인 구현의 근거를 확대하지 않는다.

## 검증

2인 사진과6공급처 지형 대응, 중앙4칸, A~E16개씩 총80개 고유 타일 추첨, 남은 타일 폐기, 획득 타일·상품 보존, seed 재현성과 차이, 저장 복원 검사를 추가했다. 브라우저에서 새2인 게임의 공급처와 중앙 배치를 확인했다.
