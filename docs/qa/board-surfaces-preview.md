# 중세 보드 표면 디자인 시범 (2026-10-28)

사용자 첨부 요청 전문을 읽고 현재 컴포넌트에 적용했다. **로컬 디자인 실험만 수행한다. Commit/Push/PR/호스팅 배포 금지.** 기준 커밋 `12e773f`이며, 기존 dirty 문서/수도원27·28 PNG/입력 자료는 별도로 보존했다.

## 적용 범위

- 빈 영지 칸: 풀밭/짙은 숲/황토·자갈/황금 들판/회색 암석/수면의 6개 질감. 기존 `estatePoints`, 중심, 반지름48, 공통 격자 경로를 그대로 사용한다. 이미지와 장식은 `pointer-events="none"`. 배치된 타일에는 적용하지 않는다.
- 영지 요구 주사위만 지형별 색상과 얕은 하이라이트/음영을 적용했다. 공통 `WhiteDie`의 실제 눈 배열, 크기36, 중심은 유지한다. 밝은 면은 짙은 눈, 성의 어두운 면은 아이보리 눈이다. 일반 흰 주사위/플레이어 색상 주사위는 유지한다.
- 포도밭: `slot.layer` 그대로 1층 `#27664A`, 2층 `#79A64C`, 3층 `#C1C99A`, 4층 `#E9C66C`. 화면 높이로 층을 추정하지 않는다. 층별 2가지 잎/덩굴/포도 질감을 사용하며, 글자 뒤만 부드럽게 밝힌다. 주사위는 기존 아이보리. 기존 24칸/12자리, 계단 경계/흰 측면/확대/배치/회전은 유지한다.
- 개인/포도밭 배경: 약한 종이 섬유, 얕은 가장자리 음영, 옅은 지도 펜화. 공용보드: 기존 SVG 양피지 그라데이션/장식에 미세한 SVG 섬유 패턴. 목재 프레임은 기존 CSS 테두리 폭 안에서만 적용한다.
- 점수표/확장/도감/팝업/설정/행동 안내에는 매우 약한 양피지. 버튼에는 얕은 하이라이트만 적용하며, 주사위 선택 강조 및 빨간 턴 버튼은 유지한다.
- 게임 엔진, 서버, 저장 포맷, 난수, 기존 일러스트/보상 PNG, 클릭 영역은 변경하지 않았다. 새 상태나 의존성도 추가하지 않았다.

참고 시안의 분위기를 SVG 브러시/잎/돌/물결로 표현한 **질감 시범**이며, 시안 전체를 게임 보드 이미지로 덮지 않는다. 생성 스크립트의 고정 시드는 게임 난수와 무관하다. 동적인 SVG 노이즈 필터 대신 미리 렌더링한 256×256 WebP 16장(합계75,810바이트)을 캐시하여 사용한다. 지도 장식은 별도 작은 SVG다. 외부 이미지 서버나 생성형 API에 의존하지 않는다.

증거/로그는 모두 제외 폴더 `.local-data/texture-preview/`에 보관한다. 세부 최종 결과는 PROGRESS의 이번 접두사에 기록한다.

초기 문제는 숨기지 않았다. 종이의 반복 원형 음영을 제거했고, 포도밭 텍스트 바탕을 부드럽게 다듬었다. 새 테스트의 fixture는 실제 배치1장인데 2장으로 기대한 오류를 바로잡았다. 초기 코어의 임시파일 rename EPERM은 허용된 로컬 권한으로 재실행했다. 기존 공용보드의 장식 이미지0개 검사는 **그대로 유지**하고 장식을 순수 SVG 패턴으로 수정한 뒤 재검사했다. 기존 테스트 삭제/완화 없음.

실제 Android/iPhone 기기, 외부 네트워크, 운영 Redis/Render는 검사하거나 수정하지 않는다. 모바일은 브라우저 에뮬레이션이며, 원래의 나란한 보드가 작아 보일 때는 기존 각 보드 확대 버튼을 사용한다.

## 되돌리는 방법

시작 당시 원본은 `.local-data/texture-preview/before/`의 동일 상대 경로에 있다. `before.patch`는 시작 당시 전체 미커밋 diff이며 이번 디자인을 취소하기 위한 패치로 적용하면 안 된다.

이번에 바뀐 위 7개 UI 파일만 해당 백업과 비교한 뒤 복원하면 새 CSS import/질감 렌더러 연결이 제거되어 이전 화면으로 돌아간다. 원래 dirty PROGRESS/TODO도 해당 백업에 있다. 새 `board-surfaces.*`, 스크립트, 질감 폴더는 참조되지 않는 상태로 남겨도 된다. 이후 다른 수정이 생겼다면 백업 파일을 무조건 덮지 말고 이번 diff만 분리한다. `git reset`, `clean`, 미커밋 PNG 복원, 운영 데이터 조작은 필요하지 않다.
