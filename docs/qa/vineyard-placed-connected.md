# 개인 포도밭 연결형 타일·보유 사탕 20% 확대 (2026-10-28)

기준 `3461450`. 후속 요청의 과일 정방향 유지까지 포함한다. 공급처는 연결형 `VineTile`을 쓰지만 개인 포도밭은 각 칸에 완성형 육각 PNG를 직접 그리던 것이 원인이었다.

## 변경

- `src/app/vineyard-board.tsx`: 배치 타일과 배치 전 미리보기에도 기존 `VineTile connected`를 그대로 사용한다. SVG 경로·연녹색 배경·갈색 선·과일 마스크·그림 비율을 공급처와 공유한다. 새 디자인/이미지 에셋은 없다.
- 공통 SVG의 두 중심 (26,28.5)/(74,28.5), 간격 48을 렌더링 상수로 공유한다. 기존 실제 칸 중심 `c0/c1`의 거리/48로 등비 확대하고 두 중심 사이의 각도로 회전한다. 뒤집기 180°는 정확한 중심 (50,28.5)을 사용한다. 타일별 크기 보정은 없다.
- `vineCenter`, 격자 24칸·12자리, 원래 클릭 다각형, 각 칸 ID, 저장된 `tileId/flipped`, 점수·효과·서버 로직은 그대로다. 장식 SVG는 pointer-events를 끄고 원래 다각형으로 클릭한다. 빈칸과 기존 4층 경계/흰 측면도 유지한다.
- `src/app/vineyards.css`: **개인 보유 사탕 행만** `clamp(16px,7.65cqw,36px)`에서 `clamp(19.2px,9.18cqw,43.2px)`로 변경했다. 모든 반응형 구간에서 정확히 1.2배다. 기존 flex 줄바꿈과 등비 이미지를 유지한다. 공급처의 남은 사탕, 보상 선택, 점수표 아이콘은 변경하지 않았다.

## 과일 정방향 유지

- `src/app/vineyard-art.tsx`와 `vineyard-board.tsx`: 부모 슬롯 각도와 뒤집기 각도를 합한 값의 반대 각도를 **각 과일 자기 중심**에 적용한다. 타일 외곽과 두 과일의 위치는 원래 회전을 따르지만 과일 그림의 최종 회전은 0이다. SVG 계층에서 분리하며 임시 CSS나 새 그림은 없다.
- 미리보기·배치·저장 복원·온라인 두 좌석 모두 같은 렌더러를 사용한다. 과일/마스크/연결 외곽 경로와 점수/게임 데이터는 변경하지 않는다.
