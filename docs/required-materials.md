## 지금 별도 자료 없이 가능한 것

- 현재 사용자 지정160개 구성으로 2인 연습 플레이와 A~E 진행을 계속할 수 있다.
- 성·선박·광산·건물·가축·거위·수도원·상품은 자체 SVG다. 그림 표시와 확대를 위해 별도 원본 이미지가 필요하지 않다.
- 영지1~30의 도형·숫자는 이미 있으므로 같은 이미지를 다시 한 장씩 요청하지 않는다.
- 초소 공통 위치도 확보했으므로 영지23~30 각각의 초소 사진을 다시 요청하지 않는다.

## 남은 자료 및 개발을 구분

1. **공식164개 공급과 정확히 같게 할 때:** 프로젝트160개와 공식164개 사이의 차이, 가축 종/마릿수/뒷면별 수량, 건물별 뒷면 및 수도원 번호별 뒷면을 실물/출판사 구성표와 전수 대조해야 한다. 현재 구성의 공식성은 합계만으로 증명하지 않는다. 표에는 `edition,type,subtype,count,back,quantity,source`를 쓰면 된다. 현재 사용자 지정 구성의 플레이를 막는 자료는 아니다.
2. **보드 전수 독립 검수:** 2번 외29종은 팬 도감 전사를 다른 정면 스캔이나 실물과 대조하면 검증이 강화된다. 이미 존재하는 데이터를 새로 추정 생성하지 않는다.
3. **11~18번 선택적 연결 규칙:** 직선 연결이 아니라 같은 색 경로를 통한 성 연결과 두 주사위+5점의 폐기 성 회수 규칙이다. 현재 미적용인 개발 항목이며 도안 데이터가 없다는 뜻이 아니다. 별도 옵션/검사로 구현해야 한다.
4. **3·4인 정식 공급:** 기존 엔진/연습 공급 및 슬롯과 2~4인 준비 UI는 제공한다. 사용자 지정160개 구성을3·4인 정식 공급으로 확대해 표시하지 않는다. 정식 재고 검증이 필요하다.
5. **원본 그림까지 동일한 외형:** 재사용 가능한 원본 에셋과 사용 범위가 있을 때만 원본 사용을 검토한다. 현재는 자체 SVG를 사용하며 BGA 이미지·코드를 복제하지 않는다.

세부 출처와 과거 접근 결과는 board-research.md, boards/se-duchy-sheet.md, boards/border-posts.md, rules/sources.md에 있다. 이번 갱신은 현재 로컬 구현·문서 대조이며 새 인터넷 접속 결과라고 표현하지 않는다.
