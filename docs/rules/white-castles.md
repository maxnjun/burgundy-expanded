# 흰 성·수도원29

근거: 공식 Special Edition 규칙서12–14쪽, 공식 아크릴 라벨5–6쪽. 출처 검증은 [sources.md](sources.md)의 해당 절을 참조한다.

- 선택 확장 `white-castles`: 흰 성8개(베이지6·검정2), 수도원29 노랑1개를 각 공급에 혼합한다. 처음 A단계부터 등장할 수 있다.
- 흰 성은 베이지 **건물**이다. 건물 지형과 기존 도시별 동일 종류 제한을 적용한다. 일반 녹색 성이나 방패 장착 대상으로 취급하지 않는다.
- 배치 직후 현재 흰 주사위 눈으로 일반 행동1회를 한다. 기존 일꾼 순환 보정과 적용 가능한 수도원 보정을 재사용한다. 확정 전에 일꾼을 소비하지 않으며 실제 흰 주사위와 개인 주사위는 바꾸지 않는다.
- 획득/배치/상품 판매/일꾼 획득은 기존 검증된 intent를 실행한다. 부모 선택은 자식 배치 효과를 만들기 전에 소비한다. 추가 행동을 포기할 수 있으며 미해결 선택 중에는 턴을 종료하지 않는다.
- 수도원29: 자신의 영지에 배치된 흰 성마다 종료4점. 보관함 타일과 녹색 성은 제외한다. 방패10의 기존 수도원 종료 점수 배율도 적용한다.
- 기중기는 흰 성 확장이 활성화되면 흰 성의 배치 효과를 선택할 수 있다. 종료 시 즉시 효과의 선택과 무관하게 수도원16–23·29 중 유리한 건물 하나로 계산한다. 여러 수도원이 있어도 기중기 하나의4점 보너스를 중복 적용하지 않는다.
