# 기본판 규칙 요약

출처는 [sources.md](sources.md)의 `special-edition-rulebook`이다. 각 페이지는 PDF 페이지 번호다. 아래는 규칙 요약이며, 현재 실행 가능한 부분 엔진의 범위는 [core-engine.md](../core-engine.md)를 따른다. 수도원 효과는 일반 규칙의 예외가 될 수 있다.

## 1. 구성과 목표 (p.2, 4)

- 기본판은 2~4인이다. 최종 승점이 가장 높은 플레이어가 승리한다 (p.4–5, 10).
- 육각 타일 164개: 건물 56, 가축 28, 광산 12, 선박 26, 수도원 26, 성 16. 일부는 검은 뒷면이다. 앞면 종류와 공급 풀인 뒷면 색을 구분해야 한다 (p.2).
- p.2 구성품 표의 뒷면별 합계: 건물 베이지 40/검정 16, 가축 초록 20/검정 8, 광산 회색 10/검정 2, 선박 파랑 20/검정 6, 수도원 노랑 20/검정 6, 성 버건디 14/검정 2. 합계는 일반 뒷면 124/검정 40이다. 이 합계만으로 가축 수·종류별 뒷면이나 수도원 번호별 뒷면을 추정하지 않는다.
- 상품 42개(6종 각 7개), 색상 보너스 12개(6색 각 2개), 은화 24개, 일꾼 26개, 주사위 9개(4색 각 2개와 흰색 1개). 은화·일꾼은 의도된 유한 자원이 아니며 부족하면 대체물을 사용한다 (p.2).

## 2. 게임 준비 (p.4–5)

- 2인 전용 공용 보드 면과 3~4인용 면을 구분한다 (p.4–5).
- 타일을 뒷면 색으로 분류한다. 가축·건물·수도원·검은 뒷면 타일은 해당 주머니, 성·선박·광산은 별도의 공개 공급으로 준비한다 (p.5).
- 상품 42개를 섞어 5개씩 다섯 묶음을 단계 A~E에 둔다. 남은 17개에서 플레이어별 시작 상품 3개를 무작위로 지급하고 미사용 상품은 상자에 넣는다 (p.5).
- 색상별 큰 보너스(5/6/7)를 작은 보너스 위에 쌓는다 (p.5).
- 각 플레이어는 영지, 해당 색 주사위 2개, 은화 1개, 시작 상품 3개 등을 받는다. 같은 종류 상품은 쌓고 다른 종류는 다른 보관 칸을 쓴다 (p.5).
- 주사위 최고 눈으로 시작 플레이어를 정한다. 시작 플레이어부터 시계방향으로 일꾼 1·2·3·4개를 받고 순서 트랙 첫 칸에 같은 순서로 위에서 아래로 표식을 쌓는다 (p.5). 최고 눈 동률 재굴림 절차는 원문에 명시되지 않아 미확정으로 남긴다.
- 원하는 성 칸에 시작 성 1개를 놓는다. 초보자용 영지 1·2에서는 중앙 6번 칸을 권장한다. 시작 성은 점수를 주지 않으며 1칸 성 구역이라도 동일하다 (p.5, 9).
- 기본판 영지는 번호 1~10이다. 정확한 칸별 색·눈·연결 정보는 별도 데이터 검증이 필요하다 (p.2, 5).

## 3. 단계·라운드·차례 (p.6, 10)

- 게임은 A~E 다섯 단계이며, 단계마다 다섯 라운드다. 총 25라운드, 플레이어당 기본 주사위 행동 50회다 (p.6, 10).
- 단계 시작 시 공용 보드에 남은 육각 타일을 상자로 돌려보낸다(A 시작 제외). 공급처에 남은 상품은 제거하지 않는다 (p.6).
- 번호 공급처의 정해진 색 슬롯과 검은 공급처를 보충한다. 현재 단계의 상품 5개를 라운드 칸에 공개한다 (p.6).
- 각 라운드 시작에 모든 플레이어가 자기 주사위 2개를 동시에 굴린다. 순서 트랙 선두(동률은 맨 위)가 흰 주사위도 굴린다. 모든 눈은 공개된다 (p.6).
- 라운드 상품 중 아래쪽부터 첫 상품을 흰 주사위 눈과 같은 번호 공급처에 놓는다. 기본판에서 흰 주사위는 플레이어 행동에 사용하거나 일꾼으로 바꾸지 않는다 (p.6).
- 순서 트랙에 따라 차례를 진행한다. 표식이 같은 위치면 위에서 아래 순서다. 선박으로 순서가 바뀔 수 있으므로 좌석 순서를 차례 순서로 고정하지 않는다 (p.5–7).
- 각 차례에 주사위당 행동 1회, 총 2회다. 같은 행동을 두 번 하거나 원하는 순서로 조합할 수 있다. 사용한 주사위는 사용 영역으로 옮긴다 (p.6–7).

## 4. 일꾼과 네 가지 기본 행동

### 일꾼 보정 (p.6)

일꾼 1개를 반납해 자기 주사위 눈을 +1 또는 -1 한다. 1↔6 순환이 가능하고 여러 일꾼을 사용할 수 있다. 일꾼 사용 자체는 행동이 아니다. 수도원에 의해 보정 규칙이 달라질 수 있다 (p.11).

### 타일 가져오기 (p.7, 9)

주사위 눈과 같은 번호 공급처에서 육각 타일 하나를 가져와 개인 보관 칸에 둔다. 영지에 바로 놓지 않는다. 보관 칸이 가득 차면 기존 타일을 버려 공간을 먼저 확보할 수 있다. 기본 보관 칸은 3개다 (p.5, 7). 건물 효과로 얻는 타일 역시 보관을 거친다 (p.9).

### 타일 영지에 놓기 (p.7–9)

보관 타일을 같은 색이며 주사위 눈과 같은 번호의 빈 영지 칸에 놓는다. 기존 배치 타일 하나 이상과 변을 공유해야 하며, 첫 배치는 시작 성과 인접해야 한다. 영지에 놓인 타일은 이동·제거·교체할 수 없다. 배치하면 해당 효과와 구역 완성을 처리한다.

### 상품 판매 (p.10)

주사위 눈에 대응하는 종류의 상품을 전부 판매한다. 일부만 팔 수 없다. 판매 상품을 개인 보드 아래에 뒤집어 두고, 묶음 전체에 은화 1개와 상품 타일당 2/3/4점(2/3/4인)을 받는다.

### 일꾼 2개 획득 (p.10)

아무 눈의 주사위 하나로 일꾼 2개를 받는다. 수도원 13·14가 이 행동을 바꿀 수 있다 (p.11).

## 5. 타일 효과

| 종류 | 효과 | 페이지 |
| --- | --- | --- |
| 수도원(노랑) | 번호별 지속 효과 또는 종료 점수 효과 | 7, 11–12 |
| 선박(파랑) | 원하는 번호 공급처의 상품을 보관 가능한 만큼 가져오고, 순서 표식을 한 칸 전진시킨다. 같은 위치의 표식 위에 놓는다 | 7 |
| 성(버건디) | 원하는 주사위 눈 하나를 추가로 가진 것처럼 즉시 추가 행동 1회 | 7 |
| 광산(회색) | 즉시 효과 없음. 단계 종료마다 영지의 광산당 은화 1개 | 8, 10 |
| 가축(초록) | 새 타일의 가축 수를 득점하고, 같은 목초지의 같은 종류 기존 가축 수도 다시 득점한다. 타일끼리 직접 인접할 필요는 없지만 같은 연결 초록 구역이어야 한다 | 8 |
| 건물(베이지) | 종류별 일회성 배치 효과. 같은 연결 도시 구역에 같은 건물 종류는 하나만 허용(수도원 1 예외) | 8–9, 11 |

선박으로 얻는 상품은 최대 3종류까지 보관한다. 이미 가진 종류는 쌓을 수 있으며 보관할 수 없는 상품은 공급처에 남긴다. 선택하는 공급처는 선박 배치에 사용한 주사위 눈과 무관하다 (p.7).

### 건물 8종 (p.8–9)

| 건물 | 배치 효과 | 페이지 |
| --- | --- | --- |
| 시장 | 번호 공급처에서 선박 또는 가축 1개를 보관으로 획득 | 8 |
| 목공소 | 번호 공급처에서 건물 1개를 보관으로 획득 | 8 |
| 교회 | 번호 공급처에서 광산·수도원·성 중 1개를 보관으로 획득 | 8 |
| 창고 | 원하는 상품 종류 한 묶음을 주사위 없이 판매 | 9 |
| 숙소 | 일꾼 4개 | 9 |
| 은행 | 은화 2개 | 9 |
| 시청 | 보관 타일 하나를 추가 배치하고 그 효과도 처리 | 9 |

획득형 건물 효과는 중앙 검은 공급처를 선택하지 않는다. 건물의 추가 효과에 별도 주사위는 필요 없다. 즉시 효과를 사용할 수 없어도 해당 건물 자체는 배치할 수 있다 (p.8–9). 시청 연쇄의 구체적인 선택·중단·보정 처리는 인터페이스의 대기 효과로 표현하고 구현 전에 검증한다.

## 6. 검은 공급처 구매 (p.10)

각 차례에 주사위 행동과 별개로 한 번, 은화 2개를 지불해 검은 공급처 타일 하나를 보관한다. 두 주사위 행동 전·사이·도중·후에 가능하다. 무제한 구매나 즉시 영지 배치가 아니다.

## 7. 점수와 종료

- 연결된 같은 색 구역을 전부 채우면 크기에 따른 점수와 현재 단계 보너스를 즉시 받는다 (p.9).
- 구역 크기 1/2/3/4/5/6/7/8의 점수는 각각 1/3/6/10/15/21/28/36점이다. 단계 보너스 A/B/C/D/E는 10/8/6/4/2점이다. 2026-10-17 Phase 1 재검토에서 p.4 공용 보드 왼쪽 점수표를 렌더링해 직접 대조했다. p.9 본문의 범위를 수열로 추측한 값이 아니다. 기존 U04는 해소했다.
- 영지의 한 색 전체를 가장 먼저 채운 플레이어는 2/3/4인에서 5/6/7점, 두 번째는 2/3/4점을 받는다 (p.9).
- 다섯 라운드가 끝나면 광산 수입과 해당 수도원 효과를 처리하고 다음 단계로 간다 (p.10–11).
- E단계 종료 후 남은 상품당 1점, 은화당 1점, 일꾼 두 개당 1점, 배치한 종료 점수 수도원 효과를 추가한다. 보관 타일은 영지 타일로 계산하지 않는다 (p.10–12).
- 최종 동점이면 영지의 빈칸이 더 적은 플레이어, 그래도 같으면 순서 트랙에서 더 뒤인 플레이어가 승리한다. 그 이후 완전 동률 처리는 미확정이다 (p.10).

## 9. 인원별 준비 차이 (p.6, 10)

- 4인: 3~4인 면의 ‘4’ 슬롯까지 보충한다.
- 3인: ‘4’ 슬롯을 쓰지 않는다. 6번 공급처의 성 슬롯은 A/C/E에 성, B/D에 광산으로 보충한다.
- 2인: 공용 보드를 뒤집어 2인 면을 사용한다.
- 각 면의 정확한 슬롯 수·색상·검은 공급처 배치는 별도 검증 전까지 실행 데이터로 생성하지 않는다.
