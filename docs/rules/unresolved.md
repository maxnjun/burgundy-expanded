## 이번 단계에서 보장하지 않는 것

- 타입 검사 통과는 규칙 준수나 실제 플레이 가능성을 증명하지 않는다.
- `readonly`, 숫자 필드 및 ID는 런타임 유효성 검사를 대신하지 않는다. 기존 boards 검증기와 core 상태/행동 검증기는 각자의 범위만 검사한다. 공식 기하·전체 게임 준비·외부 저장 JSON의 검증은 별도이며 타입 검사로 대체하지 않는다.
- 기본판은 2~4인이다. 타입의 1인 값과 확장 모드들은 향후 모듈 경계만 표현하며 지금 지원되는 실행 모드가 아니다.
- src/game/core의 지원 범위에는 실행 로직과 단위 테스트가 있다. 전체 GameEngine이나 기본판 완성은 아니며 미구현 처리는 오류로 반환한다. 빈 배열·가짜 성공·임의 점수로 규칙 공백을 채우지 않는다.
- 필요한 추가 증거는 이 PDF의 선명한 도표 또는 정식 부속 보드·타일 자료다. BGA의 코드나 그래픽으로 빈 부분을 채우지 않는다.
