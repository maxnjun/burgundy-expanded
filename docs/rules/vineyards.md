- 배치 전 그림을 60°씩 회전한다. 고정된 이중 슬롯의 실제 두 중심을 기준으로 방향이 같은 슬롯만 선택할 수 있다. 반대 방향은 기존 `flipped` 값으로 표현하므로 좌표·주사위·색상 연결·저장 배치 형식은 바뀌지 않는다. 포도밭 자체의 확대/이동은 UI 상태다.
- 은화2·일꾼4·승점4 등 확정 보상과 남은 한 칸 보상의 시작은 자동 처리한다. 타일·상품·토큰 종류 등 실제 여러 선택은 그대로 선택한다. 효과 중복 요청은 기존 엔진 choice/revision/요청ID 검사로 거부한다.
- V12의 검은/상점 획득은 기존 복원판 데이터대로 일반 6종 또는 포도 상점 타일을 무료로 가져온다. 여관은 제외한다. 다른 건물형 보상은 기존 종류 제한을 유지한다. 무료 획득과 은화 구매는 다른 액션이며, 보상 처리 중 별도 유료 구매는 명시적인 구매 모드로만 입력한다.
- 등록된 개인 포도밭 좌표는 `project-vineyards-v2` 1종뿐이다. 새 게임은 플레이어별 지원 보드ID를 저장한다. 기존 저장에 없는 ID는 공통 기존 좌표를 유지하며 재추첨하지 않는다. 서로 다른 보드를 무작위 배정하는 것은 추가 보드 데이터 확보 전 보류한다.
