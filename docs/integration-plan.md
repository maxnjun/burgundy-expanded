## 초기 감사

- 기본판 엔진은2~4인 competitive 전용. UI 준비는2인만 제공하며3/4인은 연습 공급이다. 모든 controller는human으로 검사한다. 모드 타입/확장 인터페이스 존재는 실행 기능의 증거가 아니다.
- 사용자 지정160개 카탈로그와 사진 기준2인 슬롯, 영지1~30은 존재한다. 공식164개 전수 검증은 별개다.
- 기본 수도원1~26·건물8종·거위·초소는 존재한다. 수도원27~29·기중기·방패·무역로·포도밭·샤토마는 미구현이다.
- 솔로는 단순1인 기본판이 아니다. 강을 통한 확장, 상품5개 교환/검은 무효과 타일, 색 완성 직접 배치, 점수 목표 재설정이 필요하다. 팀전도 단순 점수 합계가 아니라 실제 공유 영지·자원·개인2칸/공유2칸 보관이 필요하다.
- 영지31/32 팀 보드와33/34 솔로 보드의 칸·연결 데이터는 현재 카탈로그에 없다. 공식PDF p.15에는 팀·솔로 예시 사진이 실제로 있다(이번에 렌더 확인). 도상이 없다고 단정하지 않고 확대 원본 전사와 강/접점 그래프 검증이 필요하다. 기존1~30 보드를 그 보드로 위장하지 않는다.
- 일반 AI는 공식 샤토마와 구분하여 구현한다. seed 난수나 아직 공급되지 않은 타일을 미리 읽어 유리한 선택을 하지 않는다.
- 온라인 구현 코드를 작성하더라도 localhost 검증만으로 외부 인터넷 서비스/영구 서버가 배포되었다고 표시하지 않는다. 외부 공개와 권한 변경은 승인 없이 실행하지 않는다.
