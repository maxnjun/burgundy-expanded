# 직접 보드 조작

입력 개편은 자체 SVG와 기존 GameAction 엔진을 사용한다. BGA 소스나 이미지를 복제하지 않는다.

- 주사위 → 일꾼 자원 아이콘: 즉시 일꾼 획득.
- 주사위 → 공급 타일: 표시한 일꾼 비용을 확정 시에만 소비하고 첫 빈 보관 칸에 획득.
- 주사위 ↔ 보관 타일 → 강조된 영지 칸: 두 선택 순서 모두 지원하며 칸 터치로 배치.
- 주사위 → 상품: 같은 종류 상품을 판매하고 은화·VP·추가 일꾼을 엔진에서 처리.
- 주사위 → 방패 → 강조된 자기 성: 두 미사용 주사위와 최소 보정 비용으로 장착. 기존 방패 교체는 확인 후 실행하며 공급 슬롯은 null 실루엣으로 남는다.
- 보관함이 가득 차면 공급 타일 → 교체할 보관 타일 → 교체 확인. 대상을 임의 폐기하지 않는다.
- 검은 공급처는 은화2로 직접 구매한다. 수도원6 획득 방식은 ‘특수 행동’에서 명시적으로 선택하며 일반 주사위 획득과 구별한다.

주사위를 선택하지 않았거나 해제한 상태에서는 공급처/방패 비용 배지를 숨긴다.

주사위를 다시 누르면 해제하고 다른 주사위를 누르면 변경한다. 타일 선택·취소·이동·확대만으로 자원이나 주사위를 사용하지 않는다. 선택은 고정된 작은 도구 모음에 표시한다. 기록은 접이식 패널에서 확인한다.

## 엔진과 비용

`directActions`는 기존 합법 행동 열거를 재사용한다. `cheapestDieAction`은 선택한 주사위와 대상이 같은 후보 중 실제 일꾼 비용이 가장 낮은 행동을 사용하고, 동률이면 보정 단계가 짧은 후보를 택한다. 1↔6 순환과 수도원8~12 및 방패6 공유는 기존 planAdjustment/검증 경로에 포함된다. 실행은 applyCoreAction을 다시 거치므로 선택 중 상태가 바뀌어도 위법 행동은 반영하지 않는다.

방패는 별도 directShieldActions로 두 주사위·자원·장착 성·교체를 검사한다. 일반 타일 획득 조건을 공유하지 않는다. U15 은화는 사용자 확정 프로젝트 규칙(방패9 결과 + 수도원3의 은화1)을 유지한다.

## 자동 진행

라운드 시작과 단계 처리는 짧은 지연 뒤 정상 GameAction으로 자동 실행한다. 필수 선택 또는 연쇄 효과가 남으면 멈춘다. 두 주사위를 소모하고 선택적 추가 행동도 없으면 차례를 자동 종료한다. 검은 공급처 구매·수도원6·수도원28 같은 추가 행동이 합법적으로 남으면 ‘추가 행동 없이 다음 차례’를 제공한다. AI 일시정지 상태에서는 자동 진행도 정지한다.

## 검증과 저장

기존 저장 형식은 유지한다. 주사위/타일 선택은 임시 UI 상태이며 새로고침 시 선택만 해제된다. 진행과 자원·슬롯·기록·보기 설정은 저장한다. 검사 결과와 남은 문제는 PROGRESS.md를 따른다.

온라인 브라우저 검사는 실사용 방과 다른 QA 저장소를 주입해 같은 production handlers/RoomStore를 실제 HTTP로 실행한다. 기존 `.local-data/rooms` 데이터와50개 방 한도를 변경하지 않는다. 저장 교체의 일시적인 EPERM/EBUSY/EACCES는 최대4회 시도하고 최종 실패 시 기존 저장과 임시 파일을 보존한다. 출판사 규칙 변경과 관계없는 파일 저장 처리다.
