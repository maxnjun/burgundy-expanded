# 실행·플레이·검사 안내

2026-10-18. 현재는 프로젝트 지정 공급으로 플레이하는 부분 구현이다. 통합 Phase1~8 전체 완료 상태와 구분한다.

## 실행

```powershell
npm install
npm run dev -- --hostname 127.0.0.1
```

이미3000번 서버가 실행 중이면 새 서버를 중복 실행하지 말고 그 서버를 사용한다.

- 로컬/일반 AI: http://127.0.0.1:3000/
- 같은 서버의2인 방: http://127.0.0.1:3000/online

로컬 게임 준비에서2~4인·영지1~30·시작 성·색상·첫 플레이어를 선택한다. 2인은 사용자 지정160개 공급,3/4인은 연습 공급이다. 사진 기준 슬롯을 사용한다고 전체 공급 구성이 공식164개라는 뜻은 아니다.

`일반 AI 상대`는 첫 좌석을 사람이 조작하고 나머지를 자체 휴리스틱 AI가 조작한다. `AI 시연`은 모든 좌석이 자동 진행한다. 공식 샤토마 및 공식 솔로 모드가 아니다. 일시정지하면 수동 조작할 수 있고, 일시정지도 저장된다. 자동 진행은 게임 종료 시 멈춘다.

## 모바일

타일을 탭해 선택하고, 빈칸을 탭한 뒤 화면 아래 배치 버튼으로 실행한다. 합법 조건을 만족하지 않으면 실행 버튼을 활성화하지 않는다. 일반 손가락 스크롤은 페이지를 스크롤한다.

영지의 `드래그 이동 켜기`를 누르면 한 손가락으로 보드를 이동하고 두 손가락으로 확대/축소한다. 이 모드에서는 타일을 잘못 선택하지 않도록 클릭을 막는다. 선택하려면 이동 모드를 끈다. 마우스는 기존 Alt/중간 버튼 드래그 및Ctrl+휠을 사용할 수 있다.

## 선택 추가 규칙

- 거위 및 국경 초소: 기존 구현을 유지한다.
- 추가 타일 옵션: 수도원27·28, 기중기, 거위 각1개. 사용자 지정160개에 추가4개이며, 공식 기본164개와 혼동하지 않는다.
- 수도원27: 자신이 있는 순서 표식 스택의 맨 위를 항상 유지한다.
- 수도원28: 은화1개로 일꾼2개 구매. 엔진은 자신의 차례 밖에서도 허용하며 UI는 현재 조작 좌석의 버튼을 제공한다.
- 기중기: 건물8종 효과를 선택/생략한다. 복합 건물은 기존 선택 큐를 이용한다. 종료 시 수도원16~23이 있으면 한 건물 종류로 간주해4점을 추가한다. 현재 지원 카탈로그에는 수도원29가 없어29와의 조합은 제공하지 않는다.
- 방패·공식 솔로·팀전·무역로·포도밭·샤토마는 아직 실행 기능이 아니다.

## 2인 방

한 브라우저에서 방을 만들고 방 코드를 다른 브라우저의 /online에 입력한다. 같은 브라우저의 두 탭은 같은 좌석 저장소를 공유하므로 서로 다른 사람을 검사할 때는 별도 브라우저/프로필을 쓴다.

각 좌석의 불투명 토큰은 브라우저에만 보관하고 서버 파일에는 해시만 저장한다. 참가자가 모두 들어온 뒤 서버가 제공하는 합법 행동을 선택한다. 타일/영지를 누르면 관련 합법 행동을 선택할 수도 있다. 모든 행동은 서버에서 좌석·리비전·규칙을 다시 확인한다. 오래된 화면에서 보낸 행동은409로 거절하고 새 상태에서 다시 선택한다.

방은 `.local-data/rooms/`에 보관해 같은 데이터 폴더로 서버를 다시 실행하면 재접속할 수 있다. `다른 방 선택` 후에도 같은 브라우저에서 같은 방 코드를 입력하면 원래 좌석으로 복귀한다. 브라우저 저장소를 지우면 좌석 인증도 잃는다. 로컬 게임 저장과 온라인 방 저장은 서로 덮어쓰지 않는다.

**운영 한계:** 단일 Node 프로세스·쓰기 가능한 로컬 디스크용 개발 구현이다. 외부 인터넷 서비스는 배포하지 않았다. 현재50개 방 저장 한도가 있으며 자동으로 기존 방을 삭제하지 않는다. 다중 서버/공개 배포 전에는 트랜잭션DB, 요청 제한·운영 인증/복구, HTTPS, 백업·보존 정책을 별도로 구현해야 한다. 이 작업에서는 외부 공개나 네트워크 접근 권한 변경을 하지 않았다.

## 검사

```powershell
npm run test:core
npm run test:boards
npm run test:browser
npx tsc --noEmit
npm run lint
npm run build
```

Playwright는 설치된 Microsoft Edge를 사용한다. Edge가 없는 환경은 Playwright가 지원하는 브라우저를 별도로 설치하고 config의channel을 맞춰야 한다.375/390/768/1280px에서 테스트하며 실제 휴대전화/iOS Safari 하드웨어 검증을 대신하지 않는다.

검사 JSON/스크린샷/추적 파일은 `.gitignore`로 제외한다. 브라우저 추적에는 테스트 좌석의 인증 헤더가 포함될 수 있으므로 업로드하지 않는다. 방 파일·환경 변수·비밀키·공식 PDF 및reference도 Git에 추가하지 않는다.

파일 교체 저장의 Windows `rename`과 headless 브라우저 실행은 제한된 샌드박스에서EPERM으로 실패할 수 있다. 같은 검사를 허용된 권한에서 교차 검증하고 코드 실패와 구분한다.
