# 국경 초소 위치와 득점 근거

2026-10-18 사용자 제공 표시 이미지와 공식 규칙서 p.14를 대조했다.

## 위치

- 원본: `reference/Burgundy_boards_v2-border-marked.jpg`.
- SHA-256: `4C5CB5DD728D1ECB32C4F34184EF02EE48948CD5F8CCB8747FD709E0C32DFC2C`.
- 사용자가 23번 영지에 표시한 세 곳: 왼쪽 위, 오른쪽 위, 아래 중앙의 삼각형 꼭짓점 배치.
- 공식 규칙서 p.14의 주석에 따르면 초소는 개별 영지 도안이 아니라 공통 플레이어 보드에 있다. 따라서 영지마다 다른 위치 사진을 요청할 필요가 없다. 해당 공통 배치로 다른 영지에서도 이 확장을 사용할 수 있다.
- 표시 이미지는 위치 근거로 보관했다. 게임 좌표에 초소 접점을 연결하는 데이터와 엔진·UI는 아직 구현하지 않았다.

## 규칙

공식 PDF `reference/official-rulebook-public.pdf`, p.14, Border post duchy boards (23–30):

- 놓인 타일로 두 초소를 연결하면 현재 단계에 해당하는 점수를 얻는다. A/B/C/D/E =10/8/6/4/2점이다. 같은 색 지역을 완성하는 조건과 구분한다.
- 세 초소를 모두 연결한 첫째·둘째 플레이어는 별도의 초소 보너스 타일을 받고 즉시 점수화한다. 첫째는2/3/4인에서5/6/7점, 둘째는2/3/4점이다.
- 위 위치·점수 규칙은 확인됐다. 이미 연결한 초소에 대한 중복 득점 방지, 두 연결이 같은 배치에서 생기는 경우 등은 엔진 구현 시 상태와 사례로 검증한다.

이제 ‘23~30번 초소 위치를 모른다’는 자료 요청은 해소한다. 특수 규칙이 이미 구현됐다는 뜻은 아니다.


2026-10-18 후속 갱신: 위의 ‘엔진·UI 미구현’은 위치 조사 당시 기록이다. 현재 core/border-posts.ts에 공통 접점·점유 칸 연결 검사·신규 세 쌍 연결 점수·선착순 보너스가 있으며, 준비 옵션과 영지 초소 표시/연결 수가 연결되었다. optional-rules.test.ts에서 중복 방지, 동시 연결, 두 번째 보너스 및 저장을 검사한다. 선택하지 않으면 적용하지 않는다.
