## 37칸 감사표

인쇄된 페이지 기준 위에서 아래로 r=-3…3, 각 줄은 왼쪽에서 오른쪽으로 q 증가. q 시작값은 max(-3,-r-3). C=성, M=광산, S=선박, L=가축, B=건물, Y=수도원. 뒤 숫자는 인쇄된 주사위 눈이다.

| r | 첫 q | 지형·눈 (왼쪽→오른쪽) |
| --- | --- | --- |
| -3 | 0 | C3 M4 S3 S1 |
| -2 | -1 | Y4 L5 L2 B4 B2 |
| -1 | -2 | Y5 S6 S1 Y5 Y1 M6 |
| 0 | -3 | Y6 B1 B3 C6 L3 B5 C3 |
| 1 | -3 | B2 B4 S2 B4 L2 B1 |
| 2 | -3 | M5 B1 S5 B1 L4 |
| 3 | -3 | C6 Y2 B6 L3 |

같은 지형의 변 인접으로 19개 지역을 계산한다. 사진에 이웃한 같은 색 지역을 나누는 특수 경계는 없다. 도시 크기 2/2/3/5, 선박 2/2/2, 목초지 2/4, 수도원 1/2/3, 광산 1/1/1, 성 1/1/1/1. 총 37칸이다. 성 후보는 (0,-3), (0,0), (3,0), (-3,3), 권장 시작은 (0,0)이다. 이 기본 영지에 별도 추가 규칙은 적용하지 않는다.

## 구현 범위
