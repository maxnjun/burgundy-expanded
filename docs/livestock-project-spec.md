# 프로젝트 가축 구성 확정

2026-10-18 사용자 지시: 공식 규칙서의 총량 차이와 관계없이 아래 구성을 프로젝트 기준으로 사용한다. 사용자 지정 구성이지 SE 실물 전수 대조 결과라는 뜻은 아니다. 가축 수량 재조사를 개발 선행 조건으로 삼지 않는다.

소·양·돼지·닭 각각:

| 마릿수 | 일반 뒷면 | 검은 뒷면 | 합계 |
| --- | ---: | ---: | ---: |
| 2 | 2 | 0 | 2 |
| 3 | 1 | 1 | 2 |
| 4 | 1 | 1 | 2 |
| 종별 합계 | 4 | 2 | 6 |

4종 합계는 일반16 + 검은8 = 기본24개다. 거위는2마리·검은 뒷면1개로, 거위 포함25개다. 거위는 기존 확장 타일로 구분한다.

다른 타일136개와 결합하면 프로젝트 기본 공급은160개이며 거위 포함161개다. 공식 규칙서의164개 합계에 맞추려고 가축4개를 임의 추가하지 않는다.

이 문서는 구현에 사용할 확정 사양이다. 현재 엔진의 자체 연습 공급을 실제 유한 카탈로그로 교체하는 작업과 거위 확장 효과의 구현은 별도다.

남은 기본판 자료 공백은2인 공용 보드의 정확한 전체 슬롯 배열이다. 개인 영지1~30의 지형·눈은 등록됐으며, 확장 영지의 국경 초소 표시는 별도 자료 공백이다.
