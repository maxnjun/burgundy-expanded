# Burgundy Expanded

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 기반 한국어 보드게임 UI입니다.

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 실행합니다.

프로덕션 실행:

```bash
npm run build
npm start
```

## 사용법

- 중앙 공급처의 타일을 선택하면 하단에 설명이 표시됩니다.
- SVG 영지의 빈 육각형을 선택하고 **영지에 배치**를 누릅니다.
- 배치한 타일은 공급처에서 비활성화되며 해당 플레이어 영지에 남습니다.
- 플레이어 카드 또는 **차례 마치기**로 플레이어를 전환합니다.
- 두 플레이어의 차례가 끝나면 라운드가 증가합니다.
- **주사위 굴리기**는 현재 플레이어의 주사위 두 개를 변경합니다.
- 보드의 − / + 버튼으로 80–130% 배율을 조절합니다.
- 방패/무역로 확장은 각각 문장과 교역로 표시를 전환합니다.
- 설정에서 데모 규칙을 확인하고 기본 배율로 돌아갈 수 있습니다.

## 데모 범위

정식 게임 엔진이 아닌 자유 배치 인터랙티브 데모입니다. 타일 효과, 시작 배치, 자원과 배치당 2점은 데모 데이터입니다. 인접 조건, 색상 제한, 주사위 소모, 정식 점수 계산, 확장 규칙은 구현하지 않았습니다. 라운드는 제한 없이 증가하며 상태는 새로고침하면 초기화됩니다.

외부 게임 이미지나 BGA 코드를 사용하지 않았습니다. 육각형 보드 및 장식은 자체 SVG/CSS로 작성했습니다.
